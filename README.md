# Capuchin Family Kitchen — wireframe site

A clickable dummy version of the site. Placeholder text is in [brackets].

## View it

The pages use clean URLs like `/resources/sf/`, so open them through a small
local web server rather than double-clicking an `.html` file.

- **Mac:** double-click `start.command` (the first time, you may need to
  right-click → Open). It opens http://localhost:8000 in your browser.
- **Anywhere with Python 3:** in this folder run
  `python3 -m http.server 8000` and visit http://localhost:8000

Press Ctrl+C in the terminal window to stop the server.

## Editing

The pages are generated by `build.py`. Change it and run `python3 build.py`
to rewrite them. Styles live in `assets/site.css`.
